# Registro de Uso de Inteligencia Artificial

## Projeto
Neighborhood Action Dashboard - Global Solution FIAP 2026.2

Aluno: Leonardo Bezerra Lima

Curso: Ciencias da Computacao

## 1. Ferramenta utilizada

Foi utilizado o ChatGPT, da OpenAI, como ferramenta de apoio ao desenvolvimento do projeto.

## 2. Como a inteligencia artificial auxiliou

A ferramenta foi utilizada para:

- Esclarecer conceitos de programacao em Python.
- Apoiar a elaboracao e revisao de funcoes.
- Explicar listas, dicionarios, filas, pilhas e matrizes.
- Auxiliar na identificacao de erros de sintaxe e indentacao.
- Sugerir comandos para testes no terminal.
- Apoiar a organizacao da documentacao do projeto.

## 3. Como os resultados foram verificados

Os codigos foram executados e testados no Visual Studio Code, utilizando Python e PowerShell.

Foram realizados testes de cadastro, busca, filtros, atualizacao de status, historico, estatisticas, validacao de dados, fila, pilha, hierarquia e matriz.

Tambem foram realizados testes com entradas invalidas, incluindo identificadores duplicados, categorias desconhecidas e campos obrigatorios vazios.

Os resultados apresentados no terminal foram analisados para identificar erros e verificar o funcionamento das funcionalidades.

## 4. Responsabilidade e limitacoes

O projeto utiliza dados ficticios e nao representa ocorrencias reais.

A inteligencia artificial foi utilizada como ferramenta de apoio, e suas sugestoes foram submetidas a testes durante o desenvolvimento.

O sistema e um prototipo academico e nao realiza integracao com orgaos publicos.

## 5. Consideracoes finais

O uso da inteligencia artificial contribuiu para o aprendizado de conceitos de programacao, a correcao de erros e a organizacao do projeto.

A verificacao por meio de testes foi importante para avaliar o funcionamento das solucoes implementadas.
